# Agent 協作角色

| 角色 | 主要責任 | 不自行執行 |
|---|---|---|
| 使用者 | 最終決策、優先順序、Git、Cloudflare 控制台、DNS 與外部服務授權 | 未同意的產品或架構變更 |
| Codex | 主管：架構、複雜任務拆解、驗收標準、整合與獨立驗證 | 未授權的外部異動 |
| MiniMax Code | 執行使用者指派的有限任務，回報檔案、命令、證據與風險 | 自行擴張範圍或改變架構 |
| Codex 子代理 | 執行 Codex 指派的獨立、明確、可驗證子任務 | Git、部署、外部異動或跨範圍工作 |

## 協作流程

1. 使用者決定目標與優先順序。
2. Codex 定義架構、任務邊界與驗收標準。
3. MiniMax Code 或 Codex 子代理執行有限任務。
4. 執行者回報修改檔案、命令、結果與剩餘風險。
5. Codex 讀取實際產物並獨立驗證。
6. 使用者決定是否接受、提交或進入下一階段。

## 共用 workspace

- 修改前先讀 `AGENTS.md`、`HANDOFF.md` 與相關主題文件。
- 避免兩個 Agent 同時修改同一檔案。
- 發現衝突時先停下，由使用者決定負責者。
- 代理回報只是代理證據，不等於主管驗證。

`AGENTS.sub.md` 只規範 Codex 內部子代理；MiniMax 依本文件與使用者當前指示工作。
