# 文件索引

本目錄是專案文件母索引。根目錄文件只保留入口、規則與交接資訊；詳細內容依主題拆到子索引。

## 目前文件

- [架構](./architecture/README.md)：系統架構、repo 結構與架構決策。
- [遷移](./migration/README.md)：Webflow 搬遷、資產處理與畫面一致性。
- [操作](./operations/README.md)：Preview、Production、Rollback 與環境操作。
- [第三方整合](./integrations/README.md)：LINE、Messenger、Resend 與未來服務。
- [協作](./collaboration/README.md)：Codex、MiniMax、子代理與使用者角色。
- [里程碑紀錄](./records/README.md)：依 milestone 整理的事實與證據。

## 規則

- 檔名與資料夾名稱使用英文；內容以台灣繁體中文為主。
- 每個分類使用 `README.md` 作為子索引。
- 一個事實只放在一個主要文件，其他地方以連結引用。
- `HANDOFF.md` 只保留目前狀態、阻塞與下一步，不累積完整歷史。
